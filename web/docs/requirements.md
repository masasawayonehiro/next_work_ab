## 1. 背景

札幌市内の就労継続支援A型事業所が、2026年12月25日で事業を閉鎖することになった。
そこに通う利用者は、次の通い先・働き先を短い期間で探す必要がある。

しかし必要な情報は次のように分かれていて、まとめて見比べにくい。

- 事業所の一覧：WAM NET（障害福祉サービス等情報検索）
- 募集中の求人：ハローワークインターネットサービス

## 2. 目的

閉鎖する事業所の利用者をはじめ、札幌市で就労系の障害福祉サービスや障害者求人を探す人が、
**事業所と求人を1つの画面でやさしく探して比べられる**ようにする。

## 3. 利用者像

| 利用者 | 想定する状況・必要なこと |
|---|---|
| 就労系サービスの利用者（主な利用者） | 次の事業所・求人を探している。やさしい見た目と少ない操作負担が必要 |
| 家族・支援者 | 利用者と一緒に、または代わりに探す |
| 相談支援専門員など | 候補を一覧で比べ、利用者に紹介したい |

## 4. 対象範囲

### 4.1 対象とするもの

- **地域**：北海道札幌市の全10区
- **事業所（WAM NET）**：就労選択支援・就労移行支援・就労継続支援A型・B型・就労定着支援
- **求人（ハローワーク）**：障害のある方のための求人で、就業場所が札幌市のもの
- **お気に入り**：ブラウザ内（localStorage）への星・進捗・メモの保存、エクスポート／インポート
- **画面**：さがす（`/`）とマイページ（`/mypage`）。詳細はモーダル

### 4.2 対象外とするもの（今回の版）

- 札幌市以外の地域
- 上記5種類以外の障害福祉サービス
- サーバー側の利用者登録・ログイン（アカウント）
- 問い合わせフォーム
- 事業所の空き状況・工賃・送迎の有無（元データにないため）

## 5. 機能要件

| ID | 機能 | 内容 | 状態 |
|---|---|---|---|
| FR-01 | 一覧・検索 | キーワード・サービスの種類・区・求人の有無・週の日数・雇用形態／賃金・こだわりで絞り込める | 実装済み |
| FR-02 | 種類の選択 | 5種類＋一般の障害者求人から複数選べる | 実装済み |
| FR-03 | 追加の条件 | 週所定労働日数・雇用形態・時給／月給・通勤手当／土日休み／経験不問／マイカー／社会保険／在宅 など | 実装済み |
| FR-04 | 条件の共有 | 検索条件が URL に残る | 実装済み |
| FR-05 | 詳細（モーダル） | 行を押すとモーダルで事業所・求人の詳細を表示する（別 URL の詳細ページは持たない） | 実装済み |
| FR-06 | お気に入り | 星（気になる度）・進捗・メモをブラウザに保存し、マイページで管理する | 実装済み |
| FR-07 | データの出し入れ | お気に入りを JSON で書き出し／読み込みできる | 実装済み |
| FR-08 | 出典の表示 | 全ページに WAM NET・ハローワークの出典と時点を表示する | 実装済み |
| FR-09 | データ更新 | `scraper/` と `npm run data` / `npm run data:d1` で更新できる | 実装済み |

## 6. 非機能要件

| ID | 分類 | 要件 |
|---|---|---|
| NFR-01 | 見た目 | site デザイン（白〜ピンク、15px 本文）に合わせる。コントラストは WCAG 2.1 AA を目安にする |
| NFR-02 | 操作のしやすさ | キーボード操作・フォーカス表示・スキップリンク |
| NFR-03 | JavaScript | 検索・モーダル・お気に入りはクライアント JS で動かす（site と同じ） |
| NFR-04 | スマホ対応 | 幅 375px で横スクロールが出ない |
| NFR-05 | 運用費用 | Cloudflare Pages（https://next-work-sapporo.pages.dev）。一覧データは D1 ＋ `/api/data`（フォールバックに `items.js`） |
| NFR-06 | 個人情報 | サーバーに個人情報を送らない。お気に入りは端末内のみ |

## 7. データ要件

| データ | 取得元 | 主な項目 |
|---|---|---|
| 事業所 | WAM NET オープンデータ | 名称、種別、住所、電話、定員、利用時間 など |
| 求人 | ハローワーク | 職種、賃金、雇用形態、週所定労働日数、通勤手当、保険、経験 など |

事業所と求人は法人番号・住所・名称で結び付ける（設計書 4章）。画面用データは `combined.csv` から組み立て、D1 に投入し `/api/data` で配信する（ローカル用に `items.js` も生成）。
